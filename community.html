Community & Support

Community & Support

RedFCU has two official support destinations: its Discord server for setup help, and GitHub Issues for bugs and feature requests. Ollama, a separate project, has its own channels.

RedFCU Discord

The Discord server is the project's main support channel. It holds the complete installation walkthrough and is where setup questions, Unity integration problems, and model installation get answered.

Security issues should be reported there privately rather than in a public channel or a public issue.

Join the RedFCU Discord↗ (external site)

Bugs and feature requests

GitHub Issues is the project's tracker. A useful report says what happened, how to repeat it, which model you were running, your Unity version, and includes logs or screenshots where they help.

  • RedFCU issue tracker↗ (external site)

    Bugs, feature requests, and questions that benefit from being searchable later.

  • Source repository↗ (external site)

    README, releases, license, and the project's own documentation.

  • Releases↗ (external site)

Ollama support

The links below are for Ollama, which is a separate project. They are the right place for problems with Ollama itself, not for RedFCU-specific questions.

  • Ollama documentation↗ (external site)

    Installation, model downloads, and running Ollama on your own machine.

  • Ollama on GitHub↗ (external site)

    The Ollama project's own repository, for issues and information maintained by that project.

A note on this website

This site has no contact form and collects no personal information. RedFCU questions belong in Discord or GitHub Issues; problems with Ollama belong in Ollama's own channels. Neither is operated by this website.
