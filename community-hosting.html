Community Hosting

Status: Closed until further notice

RedFCU is developing a community hosting program intended to provide hosting for approved Discord bots, software applications, and community projects.

Applications are not currently being accepted. No form, email address, or submission route is open for this program.

Overview

A managed home for approved projects

The purpose of Community Hosting is to provide a managed hosting environment for approved projects and services supported by RedFCU.

The service is currently under development while infrastructure, policies, review procedures, and security systems are being finalized.

No applications may be submitted at this time. Nothing on this page is an offer of hosting, and nothing here guarantees that a project would be accepted if the program opens.

Availability

Closed

Applications, capacity, and a launch date have not been announced.

This page describes a planned service, not a current offering.

Planned features

What the program is intended to include

These are intentions for the program, not commitments, and they do not describe anything available today.

  • Hosting for approved Discord bots

    A managed place for bots that pass review, instead of a personal machine or an unmanaged host.

  • Hosting for approved software projects

    A place for small applications and tools that RedFCU has reviewed and approved.

  • Community project support

    Support for community-run projects that need a stable place to operate.

  • Security review process

    Every project would be examined before it is allowed to run on RedFCU infrastructure.

  • Manual approval process

    A person reviews each application. There would be no automatic approvals.

  • Source code inspection

    Submitted code would be read and checked, not only scanned by a tool.

  • Project monitoring

    Hosted projects would be watched for unusual behavior after they go live.

  • Limited beta availability

    Any first opening would be small and limited, not a general launch.

Planned review process

How an application would be handled

The sequence below is the intended path if the program opens. It is not available today.

  1. 1

    Application Submitted

    A project owner sends the information RedFCU asks for, if and when applications open.

  2. 2

    Files Submitted

    Source code, configuration, and supporting files are provided for review.

  3. 3

    Security Review

    The submitted files are examined for malicious, unsafe, or unexpected behavior.

  4. 4

    Manual Review

    A person reviews the findings, the project's purpose, and its fit for the program.

  5. 5

    Approval or Denial

    The application is accepted or refused. Approval would not guarantee ongoing hosting.

  6. 6

    Project Hosted

    An approved project is deployed and monitored for as long as it remains in the program.

Security review

What a review is planned to cover

Before any project can be approved for hosting, RedFCU plans to perform a security review.

Planned review areas may include the checks listed here. They are not exhaustive, and RedFCU may ask for more information or refuse a project that raises concerns outside this list.

A review would be a judgment about whether a project is suitable for RedFCU infrastructure. It is not a security certification, a guarantee that software is safe, or an endorsement of the project's conduct.

  • Source code inspection
  • Malware detection
  • Suspicious behavior analysis
  • Dependency review
  • Configuration review
  • Runtime behavior review
  • Manual verification

Important notice

RedFCU reserves the right to:

  • Approve applications
  • Deny applications
  • Suspend projects
  • Terminate hosted projects
  • Refuse service at its discretion

Hosting availability, uptime, capacity, eligibility requirements, and final policies have not yet been finalized. Approval, if the program opens, would not create a contract or a guarantee of continued hosting.
