Troubleshooting

Troubleshooting

The complete installation walkthrough lives in the RedFCU Discord. This page covers the checks that apply to any install, and what to send when you ask for help.

RedFCU is a Unity Editor extension that talks to a model running in Ollama. When something fails, check the three pieces separately: Unity and the package, then Ollama, then the model itself.

Check the basics first

  • Windows 10 or Windows 11, 64-bit.
  • Unity 2022.3 or newer; Unity 2022.3 LTS and Unity 2023 LTS are recommended.
  • 16 GB of RAM minimum, 32 GB recommended, and 100 GB of disk space.
  • The package came from the latest GitHub release↗ (external site), not from a mirror or a re-upload. The current release is v3.0.0.
  • Ollama is installed and running.
  • The model you intend to use has been downloaded through Ollama.

These are the published requirements. The project's Computer Specs file↗ (external site) is the full version and takes precedence if it differs from this page.

The package will not import

Download the .unitypackage from the latest release and confirm the download finished. The current file is Codepilot-AI.unitypackage, about 360 KB, and it should still end in .unitypackage when the download completes.

In Unity, use Assets › Import Package › Custom Package and select the file. Getting Started walks through the order, including installing Ollama and a model.

If Unity reports errors while importing, copy the exact message from the Console before changing anything else. Menu names and settings can differ between releases, so follow the project's Discord walkthrough for the release you installed if it differs from this page.

RedFCU cannot reach a model

Ollama has to be running. The project's README states that if Ollama is closed, RedFCU cannot communicate with the local model until it is running again.

Next, confirm the model is installed. ollama list shows the models available locally, and ollama pull downloads one. Those commands and Ollama's setup belong to Ollama's documentation↗ (external site).

RedFCU does not bundle Ollama, and this site does not host it. If Ollama itself will not start or cannot download a model, use Ollama's own support channels rather than the RedFCU issue tracker.

The model is slow or memory runs out

Model performance and hardware requirements vary significantly with model size. A larger model needs more memory and generally takes longer to respond than a smaller one from the same list.

Closing other demanding applications, or trying a smaller supported model, can help. A GPU is not listed as a requirement, but speed still depends on the model and on your computer.

Unity shows errors or nothing happens

Check the Unity Console for the exact error, and check Ollama's own output as well. Note what you did immediately before the problem, whether Ollama was running, and which model was loaded.

Do not guess at a fix from an error code alone. The Discord walkthrough and the issue tracker are the places to confirm what a message means for your release.

What to include in a report

Bugs and feature requests belong in GitHub Issues↗ (external site) or the RedFCU Discord↗ (external site). A useful report includes:

  • What happened, and what you expected instead.
  • The steps that reproduce the problem.
  • The model you were using.
  • Your Unity version, and the RedFCU version you installed.
  • Logs and screenshots, where they help explain the problem.

Security issues should be reported privately in the project's Discord, not in a public channel or a public issue. Share only the logs and screenshots needed to explain the problem.

Still stuck?

The Discord server is the project's main support channel and holds the complete installation walkthrough. GitHub Issues is better for bugs that other people can search later.
