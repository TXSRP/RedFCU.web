What Red FCU is

An assistant that stays inside Unity

Red FCU is a project built for the Unity Editor. It is intended to support AI-assisted development without pulling you out of the environment where you write, test, and iterate on your project.

It is not a separate AI model and not an online AI service. Red FCU works alongside Unity and, for model access, supports models that you run yourself through Ollama.

Where it runs
Inside the Unity Editor, as part of the workflow you already use.
Where models come from
Ollama, a separate tool that runs models on your own machine. Red FCU supports locally run models through it.
What it is not
A standalone AI model, an AI company, or a hosted AI service.

The basic setup

How the pieces fit together

Red FCU is one part of a small local setup. Ollama runs the model on your machine, and the plugin connects that model to your Unity work.

  1. 1

    Get the plugin

    Download the Unity package from the project's latest release and import it into your project.

  2. 2

    Run a model locally

    Install Ollama from Ollama's official download page↗ (external site), then pull a model through it.

  3. 3

    Connect them in Unity

    Open Red FCU in the editor and point it at your local model. The project's own walkthrough covers the current menu.

The full sequence is on Getting Started.
