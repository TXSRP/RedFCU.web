Introduction

Getting started

A short setup path: import the Red FCU package, install Ollama, pull a local model, then connect the two. Where the project's own walkthrough is the better source, this page says so instead of guessing.

Before you begin

The setup has three pieces: the Red FCU package from the project's GitHub releases, Ollama, and a model that Ollama downloads and runs on your machine.

This page covers the order and the pieces that do not change. The project keeps its detailed installation walkthrough in its Discord server and in the repository README, and those are the right place to check for the current release.

  1. Get the Red FCU package v3.0.0

    Download Codepilot-AI.unitypackage from the project's latest GitHub release. With your Unity project open, double-click the file, or use Assets › Import Package › Custom Package, and import what it contains.

    Keep the file somewhere you can find it again. A later release is installed the same way, over the existing import.

    Download latest release↗ (external site) All releases↗ (external site)

    This site hosts no copy of the package and does not link to mirror sites. Install Red FCU only from the project's own repository.

  2. Install Ollama

    Ollama is the separate tool that runs models on your machine. Install it from Ollama's official download page, or use the Windows installer below if that is your platform.

    Ollama download page↗ (external site) Windows installer (OllamaSetup.exe)↗ (external site)

    The installer is provided by Ollama, not by Red FCU. This website hosts no copy of it.

  3. Download a model through Ollama

    Models are downloaded and managed with Ollama's own tools. Browse Ollama's model library↗ (external site) to choose a model, then download it through Ollama.

    Ollama command 
    ollama pull <model-name>

    Replace <model-name> with a model tag from Ollama's library. The project lists Qwen 2.5 Coder 7B, 14B, and 32B, and DeepSeek LLM 7B and 33B as supported models. Larger models need more memory and take longer to answer.

    If your machine is near the minimum specification, start with a 7B model. Requirements for each tier are on Downloads.

  4. Open Red FCU in Unity and point it at the model

    Red FCU runs inside the Unity Editor and talks to the Ollama server on your machine, so Ollama needs to be running before you ask it anything.

    Menu names and settings can change between releases, so this page does not restate them. Follow the project's installation walkthrough in Discord, or the repository README, for the release you installed.

    Setup walkthrough (Discord)↗ (external site) Repository README↗ (external site)

  5. Test the setup

    Once the plugin is running, try a small request in a test project before using it for real work. That makes it easier to see whether the model is responding and whether the configuration is right.

    If something fails, the Community & Support page lists the official places to ask: the Red FCU Discord and GitHub Issues. Ollama-side problems, such as installation, model downloads, or a local server that will not start, are covered by Ollama's own documentation.

    Community & Support Ollama documentation↗ (external site)

If you get stuck

Troubleshooting lists the checks that apply to any install, including what to include in a report. The Red FCU Discord holds the full installation walkthrough and is the fastest place for setup questions. GitHub Issues is the right place for a reproducible bug; include your Unity version, the model you are running, and what you expected to happen.

Requirements and the supported model list are on Downloads. Problems with Ollama itself belong to Ollama's documentation rather than to Red FCU.
