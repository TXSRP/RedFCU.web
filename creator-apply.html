Programs · Verified Creator

Apply for RedFCU Verified Creator

This form builds an application file on your device. Nothing is submitted from this page. Send the file to a Red FCU staff member, who reviews it manually and replies with an outcome.

Open for applications Manual review. Applying does not guarantee verification.

Read this before you apply

Verified Creator records the result of Red FCU's own review. It is not a legal determination of ownership, a copyright or trademark registration, or a guarantee of legal protection. It is also not platform-issued verification, and it does not imply that Discord, GitHub, Unity, itch.io, Steam, YouTube, X, or any other service has reviewed or endorsed your project.

Red FCU may decline any application, ask for more information, or withdraw a badge later if the information changes or the badge is misused. Nothing on this page is legal advice.

How it works

Three steps, and the middle one is yours

The site cannot send anything for you. The application only reaches staff when you choose to send the downloaded file to a staff member yourself.

  1. 1

    Fill out the form

    Answer every required question. Your answers stay in this browser until you close or reload the page.

  2. 2

    Download the file

    The form creates a JSON file named after your project. It contains exactly what you entered, plus the date.

  3. 3

    Send it to staff

    Send the file to a Red FCU staff member, for example through the Red FCU Discord. Do not post it publicly.

    The name you publish under, or the name of your team or studio.

    Include the current username, not a display name or server nickname.

    A numeric Discord ID, or a Yapin ID in the form 8a2c94c1-de91-4e73-a425-dfd178c390dc. Either one helps staff confirm they are messaging the right person.

    About the project

    A public page that shows the project and names you as its owner or representative. The address must start with https://; plain http:// is not accepted.

    Where the project appears *

    Choose every platform that applies. Choose at least one.

    List links and say what each one shows. Useful evidence includes an official project page, a repository you control, a store listing, or a public post from the project's account. One item per line.

    File ready

    Your application file has been downloaded

    The file is named . Send it to a Red FCU staff member. Nothing has been sent automatically.

    1. Find a Red FCU staff member, for example in the Red FCU Discord.

    At a glance

    Cost
    Free. Red FCU does not charge for this review.
    Account
    No Red FCU account is needed. A Discord account helps staff reply.
    Submission
    A JSON file you download and send to staff yourself.
    Decision
    Manual review. The outcome is either accepted or declined.

    What staff look at

    • Whether the project exists and matches the details given
    • Whether you own it or are authorized to represent it
    • Whether the evidence links are public and consistent
    • Whether anything raises a concern about ownership or conduct

    Staff may ask follow-up questions. A decision can take time, and a decline does not have to be explained in detail.

    Your data

    The form builds a file in this browser. It does not send, save, or upload anything, and no analytics run on this page.

    If you send the file to staff through Discord, Discord's own privacy terms cover that message. Red FCU staff review the file in their browser; the website itself stores no application.

    Privacy details

    After review

    Accepted or declined

    If the application is accepted, you receive a message and a RedFCU Verified Creator badge image. Display it unaltered, and only for the project it was issued for.

    If it is declined, staff tell you the outcome. You may apply again later with better evidence. A decline is not a finding that you do not own the project.
