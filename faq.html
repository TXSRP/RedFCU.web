FAQ

Frequently asked questions

Short answers about installing Red FCU, running local models, the license, and this website. The project's Discord server holds the full setup walkthrough.

If something failed during setup, start with Troubleshooting. For anything else, Community & Support lists the project's Discord and issue tracker.

Getting started

Is Red FCU free?

Yes. It is free to obtain and use under the Red FCU Free Use License (RFCUFUL) 1.0.0, which permits personal, educational, research, and commercial development use.

Free does not mean open source. The RFCUFUL is a custom, source-available license that restricts public redistribution and the sale of copies. Read the license summary and full text.

Do I need an account, an API key, or a subscription?

No. The project's README describes Red FCU as working without a cloud AI service, API keys, subscriptions, or AI credits. It talks to a model running locally through Ollama.

This website has no visitor accounts, no sign-in service, and no forms that send anything anywhere. A hidden panel for the project's own staff is described on Privacy; it is a local preview tool and never contacts Discord or any other service.

Where do I download the current version?

From the project's latest GitHub release↗ (external site). The current release is v3.0.0, published on 23 October 2026, and the package is Codepilot-AI.unitypackage (about 360 KB).

This site hosts no copy of the package and does not link to mirrors. A Unity Asset Store listing is in preparation, with no store link yet. Downloads lists the release and the requirements.

Does Red FCU need an internet connection?

The first setup needs an internet connection to download Ollama and a model. After that, the model runs on your own computer through Ollama, so Red FCU does not depend on a cloud AI service.

This site does not claim that every feature works offline. What a model needs depends on the model and on your computer.

Which Unity versions are supported?

The published requirements list Unity 2022.3 or newer, with Unity 2022.3 LTS and Unity 2023 LTS recommended.

The full requirements are in the project's Computer Specs file↗ (external site), which takes precedence if it differs from this page.

Does it work on macOS or Linux?

The published requirements describe Windows 10 and Windows 11, 64-bit. No macOS or Linux support has been published, so this site does not claim either works.

If you want to run it on another platform, ask in the project's Discord before relying on it.

Models and hardware

Which models can I use?

The current release lists Qwen 2.5 Coder 7B, 14B, and 32B, and DeepSeek LLM 7B and 33B as examples. The models are downloaded and run through Ollama, separately from Red FCU.

Other compatible models may work, and more may be tested in later releases. Performance and hardware requirements vary significantly with model size.

Do I need a GPU?

No. The published requirements state that a GPU is not required. Speed still depends on the model you choose and on the rest of your computer.

How much memory and disk space do I need?

The published minimum is 16 GB of RAM, with 32 GB recommended, and 100 GB of disk space. Windows 10 or 11, 64-bit, is required.

Larger models need more memory than smaller ones. The Downloads page summarises the full requirements and links to the project's own file.

Why is the model slow?

Model performance depends on the model size and on your hardware. A larger model needs more memory and usually takes longer to respond.

Closing other demanding applications, or trying a smaller model from the supported list, can help. The project does not promise a particular speed on a particular machine.

Does Red FCU send my Unity project to the cloud?

The project's README says that project files are processed through the locally running Ollama instance rather than a Red FCU cloud server, and that no external AI API key or cloud subscription is required.

This site repeats that description without independently auditing the plugin or Ollama. Their behaviour is described by the project's documentation and by Ollama's, not by this page. See Privacy for what the website itself does.

License and sharing

Can I use Red FCU for commercial work?

Yes. The RFCUFUL permits use for personal, educational, research, and commercial development activities. That covers using the plugin in your own development work.

It does not permit selling, renting, or charging a fee for copies of Red FCU, including a fee disguised as packaging, access, or distribution.

Can I share Red FCU with a friend?

Yes, privately and free of charge. You may give a copy directly to a friend or another individual recipient, as long as it is not made publicly available.

Uploading that copy to a public website, repository, or download platform is not permitted. Sharing the official repository or download link is.

Can I publish my modified version?

Not without prior written permission from the rights holder. You may modify Red FCU for your own use, keep private forks and backups, and share a modified version privately and free of charge.

Public publication or distribution of a modified version needs permission. Licensing explains how to ask.

Can I sell copies of Red FCU?

No. The license prohibits selling, renting, sublicensing, or charging a fee specifically for copies of Red FCU or modified versions.

Is Red FCU open source?

No. It is free to use, but the RFCUFUL is a custom source-available license, not an OSI-approved open-source license and not the MIT, Apache 2.0, or GNU GPL license.

The restrictions on public redistribution and sale are why the license describes itself that way. The full text is on the Licensing page.

Does this website collect any data?

No analytics, advertising, visitor accounts, forms that submit data, or cookies. Your light or dark theme choice is stored in your browser under redfcu-theme, and it is never sent anywhere. A staff preview of an edited release can add two more local keys, also never sent anywhere; Privacy lists them.

Where do I get help?

The Red FCU Discord↗ (external site) is the project's main support channel and holds the complete installation walkthrough. Bugs and feature requests can go to GitHub Issues↗ (external site).

Security issues should be reported privately in Discord rather than in a public channel or issue. Community & Support lists every destination.

Is Red FCU on the Unity Asset Store?

Not yet. A listing is in preparation and there is no store link. The GitHub release is the current way to get the package.
