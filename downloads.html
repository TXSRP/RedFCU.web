What Red FCU needs

From the project's Computer Specs.md

The project publishes its own minimum and recommended requirements. They are summarised here; the repository file is the full version and takes precedence if the two ever differ.

Unity
2022.3 or newer. 2022.3 LTS or 2023 LTS is recommended.
Operating system
Windows 10 or Windows 11, 64-bit. The project lists no other platform.
Memory
16 GB minimum. 32 GB is recommended for the larger 7B to 33B models.
Graphics
No GPU is required, because CPU inference is supported. A dedicated GPU speeds up larger models.
Disk space
100 GB free or more. Local models account for most of that space.
Models
Qwen 2.5 Coder 7B, 14B, and 32B, plus DeepSeek LLM 7B and 33B, are the models the project lists as supported.
Read Computer Specs.md↗ (external site)

Model performance and hardware needs vary with the model you choose. A model that fits the minimum specification will not necessarily feel fast.

Ollama

Third-party · Not Red FCU

External

Ollama is the separate tool that Red FCU uses for locally run models. Install it from Ollama's official site before configuring a model for the plugin.

Ollama download page↗ (external site) Windows installer↗ (external site)

The Windows installer (OllamaSetup.exe) is provided and hosted by Ollama. Version, file size, and system requirements are set by Ollama and are not published on this site. This site hosts no copy of the installer.

About this page

Red FCU links go to the project's own GitHub releases, and Ollama links go to Ollama's own site. Nothing here is a mirror or a third-party download portal.

The version, date, package name and size in the Red FCU card are read from a single data file, assets/data/release.json, so they cannot drift apart across pages. Because the download button points at GitHub's newest release, it also keeps working if a newer version appears before that file is updated.
